# Security

Report vulnerabilities in project extensions privately using GitHub Private
Vulnerability Reporting when it is enabled on the repository's Security tab.
If no private channel is configured, ask the maintainer for one without posting
an exploit, credentials or production data in a public issue.

Also report vulnerabilities in unmodified Nexus Core to Sonatype:
https://www.sonatype.com/report-a-security-vulnerability

Before releasing a new build, review upstream security notices, update affected
dependencies and test the resulting application. This independently maintained
project does not include commercial Sonatype support.
